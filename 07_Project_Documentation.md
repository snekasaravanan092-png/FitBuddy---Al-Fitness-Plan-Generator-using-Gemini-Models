# FitBuddy — Project Documentation

## Page 17 — Features, UI Principles and Future Enhancements

### Core Features
- Personalised workout plan based on goal and fitness level.
- Customised diet plan based on diet preference.
- Instant AI-powered results.
- Simple, mobile-friendly interface.
- Demo plan generation without a Gemini key.
- BMI and estimated calorie display.
- Print/save-as-PDF browser action.

### UI Principles
**Layout**
- Single-page interface.
- Clean form.
- Cards/details sections for individual workout days.

**Look and Feel**
- Green and navy visual direction.
- Large, readable text.
- Clear buttons and panels.

**Usability**
- Mobile-friendly layout.
- Minimum clicks to reach the generated result.
- Loading feedback while Gemini is processing.

### Future Enhancements
- Progress tracker.
- Weekly reports.
- AI chat coach.
- Multi-language support.
- Download plan as PDF.
- Wearable integration.
