# FitBuddy — Project Demonstration

## Page 18 — Demo Procedure

### Demonstration Steps

1. Open the FitBuddy website/application.
2. Enter the user's age, height, weight, goal, fitness level and diet.
3. Select training days and available equipment.
4. Optionally enter injuries or other notes.
5. Click **Generate with Gemini** when an API key is available.
6. Alternatively click **Generate demo plan** to demonstrate the interface without a key.
7. Wait for the loading state to finish.
8. Review the generated summary and statistics.
9. Open each workout day to view exercises, sets, reps and rest.
10. Review the meal plan and fitness tips.
11. Change inputs and regenerate to demonstrate personalisation.
12. Use **Print or save as PDF** if a printable result is required.

### Demonstration Output
The result screen is designed to show:
- BMI
- Estimated daily calorie target
- Protein target
- Water target
- Weekly workout
- Daily meals
- Tips

### Important Project Note
FitBuddy is presented as a learning project. The application itself states that it is not medical advice and recommends checking with a doctor before starting a new program.
